# Data-Analysis-Project-on-Netflix-Dataset-

NETFLIX DATA ANALYSIS

1.Project overview
Analyzed Netflix film data using Pandas and created an interactive Power BI dashboard.

2.Dataset source
Kaggle - IMDB Scores for Netflix TV Shows and Movies

3.Technologies used
- Python
- Pandas
- Matplotlib
- Power BI

4.Cleaning steps
- Removed duplicates
- Filled null values
- Standardized columns

5.Key insights & Analysis Performed
- Differentiate and count Films between Movies and Shows
- Highest runtime films
- Highest IMDb votes by year
- Films released after 2015
- Number releases by year
- Highest IMDb Scores by Film
- Number of IMDb votes by Film
- Sum of Films by  Age certification distribution

6.Dashboard
-Data Visualization Using Matplotlib
-Interactive Power BI dashboard built using cleaned CSV data.
